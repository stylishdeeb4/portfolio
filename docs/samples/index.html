シフト給料ラボ 操作ガイド実在のアプリが題材

自作アプリを題材にした操作マニュアルです。実際の画面を撮影し、赤枠・番号で注目箇所を示しています。 手順・計算ルールの表・注意書き・FAQまでを含む構成で、Webページとしてそのまま閲覧できます。

  • 実画面のキャプチャに、赤枠と番号バッジで注釈を追加
  • 番号と説明文を対応させ、どこを指しているか迷わない形に
  • 間違えやすい入力（休憩を「分」で入れる等）は警告ボックスで明示
  • 計算ルールを表で整理し、算出根拠を追えるように記載

企画提案書：シフト給料アプリの企画実在のアプリが題材

自作アプリについて、背景と課題からロードマップまでをまとめた提案書です（全10枚）。 課題整理 → ターゲット → 解決策 → 機能 → 他手段との比較 → 開発計画 → 成果、という順で構成しています。

  • 表紙／目次／課題／ターゲット／解決策／機能／比較表／ロードマップ／数値／まとめ
  • 色は3色に絞り、見出し・本文・補足の階層を全ページで統一
  • 比較表と数値スライドで、主張の根拠を示す構成

サービス紹介資料：手順書クラウド「テジュン」架空サービスのデモ

BtoB向けサービス紹介資料のデモです（全8枚）。実在しない架空のサービスを題材に、 課題提起 → サービス概要 → 特長 → 導入の流れ → 料金 → 効果、という営業資料の型で構成しています。

  • 料金プラン表・導入ステップ・効果指標など、営業資料に必要な要素を一通り収録
  • 架空である旨と、数値が実データでない旨を資料内に明記
