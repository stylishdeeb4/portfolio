SAMPLE 01 / IT SUPPORT

「PCが動かない」を伝わる相談に。
社内ヘルプデスクへ連絡するときの5項目

想定読者：PC操作に詳しくない社員・新入社員
目的：原因を決めつけず、調査に必要な情報を文章で伝えられるようにする

「さっきまで使えていたのに、急に開かなくなった」。仕事中にPCの不具合が起きると、焦ってしまいます。急いで連絡したものの、「何を開こうとしましたか」「画面には何と出ていますか」と質問が続き、説明に困ることもあるでしょう。

相談するとき、専門用語を覚える必要はありません。まずは、何をしたときに何が起きたのかを、見えたまま伝えてみてください。この記事では、最初の連絡で整理しておきたい5項目を紹介します。分からない項目は空欄でも構いません。調べるために連絡を遅らせないことも大切です。

1．「したかったこと」と「起きたこと」を分ける

「PCが壊れました」だけでは、電源が入らないのか、特定のアプリだけ開かないのかが分かりません。原因を推測するより、操作と結果を分けて書くと状況が伝わります。

したかったこと：勤怠システムで出勤時刻を登録したい 行った操作：ログイン後に「登録」を押した 起きたこと：「処理に失敗しました」と表示され、時刻が反映されない

この例なら、PC全体の故障と決めつけず、勤怠システムで起きている問題として相談できます。「画面が白くなる」「クリックしても反応しない」といった表現も、実際に見た状態なら役に立ちます。

2．いつから起きているかを書く

発生した時刻と、最後に正常に使えた時点が分かれば添えましょう。「今日の朝から」よりも「9時10分ごろに初めて発生。昨日の退勤時には使えた」と書くと、確認する時間帯が絞れます。

正確な時刻を覚えていないときは、「昼休みの後」「14時ごろ」でも十分です。アプリの更新など、直前に気づいた変化があれば事実だけ記載します。「更新が原因です」と断定する必要はありません。

3．エラーの文章を残す

画面にエラーが出ている場合は、表示文と番号をそのまま控えます。長い文章ならスクリーンショットも選択肢です。Windowsでは、Windowsキー＋Shift＋SでSnipping Toolの切り取り画面を開けます。必要な範囲を選び、画像として保存できます。操作方法はMicrosoftの公式案内で確認できます。

共有前には、相談と関係のない顧客情報や別のチャットが写っていないかを確認してください。画面全体を撮るより、エラー部分に範囲を絞ると伝えたい内容も見つけやすくなります。パスワードや認証コードは送らず、社内で指定された窓口を使います。

4．影響の範囲と仕事の期限を伝える

ほかのアプリは使えるのか、特定のファイルだけ開けないのか、分かる範囲で書きます。同僚にも同じ問題が起きていると分かっているなら、その情報も添えましょう。調査のために、ほかの人のアカウントを借りる必要はありません。

「急ぎです」に加えて、「本日15時締切の申請が送れない」のように、止まっている業務と期限を伝えると、対応の優先度を判断する材料になります。自分だけの問題か分からない場合は、そのまま「ほかの人への影響は未確認」と書けば大丈夫です。

5．試した操作と結果をセットにする

すでにアプリを閉じて開き直したなら、「開き直しても同じエラー」と記載します。結果を書けば、担当者は次に確認する内容を考えやすくなります。何も試していない場合も、正直にそう伝えて問題ありません。

相談内容を充実させようとして、慣れない設定変更を重ねる必要はありません。保存前の作業がある、再起動してよいか分からない、といった事情も先に共有しましょう。端末情報を聞かれたとき、Windowsのエディションとバージョンは「設定」→「システム」→「バージョン情報」で確認できます。

そのまま使える相談メモ

【困っていること】 勤怠システムに出勤時刻を登録できません。 【操作と表示】 ログイン後に「登録」を押すと、「処理に失敗しました」と出ます。 【発生時刻】 今日9時10分ごろ。昨日の退勤時には使えていました。 【影響・期限】 メールなどは使えています。勤怠の提出期限は本日15時です。 ほかの社員への影響は未確認です。 【試したこと】 画面を開き直しましたが変化はありません。 再起動や設定変更はしていません。

相談の準備で目指すのは、原因を自分で突き止めることではありません。担当者が状況を確認できる材料を渡すことです。「何をしたか」「何が起きたか」「いつまでに困っているか」の3点から書き始めれば、短い文章でも伝わる相談に近づきます。

操作手順の確認元（2026年9月26日確認）：
  • Microsoft：Snipping Toolを使ってスクリーンショットをキャプチャする
  • Microsoft：Windowsデバイスに関する情報を見つける
情報の整理方法と相談メモは、本サンプル独自の構成例です。実際の対応は勤務先の手順に従ってください。
SAMPLE 02 / SALON COLUMN

はじめてのエステ予約。
不安を減らすために聞いておきたい3つのこと

想定読者：エステに興味はあるものの、初回予約を迷っている方
目的：料金・当日の流れ・相談内容を整理し、納得して予約を検討できるようにする

「少し気になるけれど、何を聞いたらいいのか分からない」。はじめてエステを予約するとき、メニューの名前だけでは当日の様子を思い浮かべにくいことがあります。

予約前に、詳しい美容知識を身につける必要はありません。知りたいことを短い言葉にして、お店に確認するところから始めてみましょう。今回は、初めての方が確認しやすい3つのポイントをご紹介します。

1．当日支払う金額は、どこまで含まれている？

メニューを選ぶときは、掲載されている価格とあわせて、料金に含まれる内容を確認しておくと安心です。例えば、カウンセリング、施術、追加オプションがそれぞれどう扱われるのか。初回価格がある場合は、対象条件と通常価格も見ておきましょう。

質問は、難しく考えなくて大丈夫です。

「このメニューを希望しています。初回に支払う総額と、追加料金が発生する場合の内容を教えていただけますか？」

「続けるかどうかは、初回の後に考えたい」と思っているなら、1回だけの利用ができるかも聞いておくと、希望を共有できます。価格の安さだけで決めず、自分が納得できる内容かを確認するための質問です。

2．入店から退店まで、どのくらいかかる？

予定を組むときに知りたいのは、施術そのものの時間だけではありません。受付、相談、着替え、お会計などを含めた滞在時間を聞いておくと、その後の予定を考えやすくなります。

仕事の帰りに立ち寄りたい、家族の予定までに帰りたいなど、時間の希望があれば最初に伝えましょう。希望の終了時刻に間に合うかを、予約前に相談できます。

「初めて伺います。入店から退店までの目安は何分くらいでしょうか。17時にはお店を出たいと考えています」

あわせて、来店時に持っていくものや準備があるか、遅刻・変更・キャンセル時の連絡方法も確認しておきます。準備の内容はお店やメニューによって異なるため、予約先の案内を受け取りましょう。

3．悩みをうまく説明できなくても大丈夫？

「きれいになりたい」という気持ちを、最初から専門用語に置き換える必要はありません。「写真に写ったときに気になる」「人と会う前に身だしなみを整えたい」のように、普段の場面から言葉にしてみてください。

まだ施術を決めていない場合は、「メニュー選びから相談したい」と伝えます。相談だけでも受け付けているか、施術を決めるタイミングはいつかを聞くことで、当日の流れを把握できます。

また、分からないことは質問として残して構いません。「何回必要ですか」だけでなく、「どのような説明を受けてから判断できますか」と聞いてみるのも一つの方法です。回数や変化を記事だけで決めつけず、自分の希望とお店の説明を照らし合わせて考えましょう。

最初の連絡は、短くて大丈夫

3つの確認点をすべて長文にする必要はありません。気になるメニュー、日程、不安に感じていることを一つずつ添えれば、相談を始められます。

「初めての利用を検討しています。メニュー選びから相談したいのですが、予約方法を教えていただけますか。あわせて、初回の費用と滞在時間の目安も知りたいです」

すぐに予約を決められなくても、料金や流れが分かれば、判断に必要な材料がそろいます。自分が何を知りたいのかを確かめながら、納得できる一歩を選んでください。

特定店舗の料金・施術内容・効果を断定しない、汎用のコラムサンプルです。実際の店舗記事にする際は、料金、所要時間、相談受付、変更・キャンセル条件を発注者に確認して反映します。医療的な効果の説明は含めていません。
