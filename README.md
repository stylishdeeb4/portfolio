## 公開設定

GitHub Pages を `main` ブランチの `/docs` フォルダから配信する設定にしています。
（Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/docs`）

## 更新手順

1. `docs/index.html` を編集
2. commit → push
3. 数十秒〜数分で公開URLに反映
